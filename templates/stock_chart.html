Chart interactions

  • Hover: shows tooltip values for candle/indicators.
  • I: toggle Inspect mode.
  • L / T: toggle Level / Trendline drawing modes.
  • FR / PC: draw Fib Retracement / Parallel Channel.
  • FB / SM / EM / ST: add indicators (Fib Bands, SMA, EMA, SuperTrend).
  • Alt+Click in Inspect: add level at OHLC/MA snap.
  • Right-click: open add menu (Level, drawings, indicators).
  • + Level: enter level draw mode, click chart to place exact price.
  • Esc: exit Inspect/cancel drawing and close open panels.
