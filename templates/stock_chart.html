Chart help

  • Modes
  • Hover — tooltip for candle, volume, and overlays (use the Tooltip button to choose fields).
  • Inspect (I or toolbar) — crosshair snaps to OHLC and MA values; RSI pane stays in sync.
  • Draw (L, T, FR, PC, or toolbar) — place levels and drawings; crosshair is hidden while drawing.
  • Keyboard shortcuts
  • I — toggle Inspect mode on/off.
  • L — toggle Level draw mode (click chart for exact price; new levels default to dashed, width 1).
  • T — toggle Trendline draw mode (two clicks: press, then click).
  • FR — toggle Fib Retracement draw mode (two clicks).
  • PC — toggle Parallel Channel draw mode (three clicks).
  • FB, SM, EM, ST — add Fib Bands, SMA, EMA, or SuperTrend (type the pair within ~0.6s).
  • Alt+Click (Inspect only) — place a level at the snapped OHLC/MA price (preferred over selecting indicators).
  • Delete / Backspace — remove the selected indicator, level, or drawing.
  • Esc — exit Inspect/draw mode, cancel in-progress drawing, close panels, and clear selection.
  • Objects & chart
  • Click an object — select it (indicator line, level, or drawing).
  • Double-click an object or its chip — open the property panel.
  • Drag a level — change price; drag trendline handles — reshape.
  • Double-click empty chart or RSI pane — reset zoom to default.
  • Right-click the chart — add menu (level, drawings, indicators) or object properties when over a hit target; save/copy chart image.
  • Press the same draw shortcut again (L, T, FR, PC) to exit draw mode.
